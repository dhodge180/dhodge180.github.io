A very short demo

A short screencast covering stepping through a pre-defined solution: pressing ➡ (Right arrow), using Ctrl + 1/2/3 to add colours, and Delete to clear colours.

Input Methods: Two ways of demo-ing a problem

Chess Navigator doesn't enforce chess rules -- beyond castling, en passant and promotion. It's a presentation tool, not an engine.

Mouse-based demonstration

Pick up and place any piece, anywhere. Good for showing an idea that isn't part of the prepared line. You can still press U (Undo) and I (Redo) to Undo and Redo moves. Use Q/R/B/S/P to complete promotions.

Solution tree navigation

Use the arrow keys to move through a pre-defined tree of FEN positions -- a solution, a try, or several tries before the true key. Play a move to improvise, then resume tree navigation right where you left off.

The pre-defined sequence is defined in a text file like PROBLEM_LIST.txt which was loaded when the program was run.

Various keyboard shortcuts

Press H the moment the program launches to see the full list. Here are some of the most important:

KeyAction
⬅ / ➡Step through the solution tree
+ / −Cycle board and piece size
HomeJump to the start of the problem

F1 or PageDownLoad the next problem (if multiple problems in a file)
F3 or PageUpLoad the previous problem (if multiple problems in a file)

Feature notes

Windows / Linux / macOS

  • Written in Python, tested on Linux and Windows, and reported to work on macOS too.
  • A Windows installer is available in the releases -- Windows will warn you it's from an unrecognised publisher; that's expected for a small hobby project.

Solution trees & custom syntax

  • Pre-stored problems are defined with a custom syntax in PROBLEM_LIST.txt -- see Sample_PROBLEM_LIST.txt for the format.
  • The syntax can express unusual rules by chaining moves together -- an anti-circe example is included in the sample file.

Fairy pieces

  • Fairy pieces used in a diagram appear automatically in the side panel.
  • Defined in custom_pieces.yml -- add your own pieces, families, and even custom images.
  • Naming follows the Popeye piece conventions.

Look & feel

  • Colours, font sizes, and animations are all customisable via config.json.
  • Six board and piece sizes, cycled with + / −.

Everything's public

Source, README, cheatsheet and the Windows installer all live on GitHub.
